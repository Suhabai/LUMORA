# LUMORA — DESIGN.md

# Design Constitution

This document defines the complete design language, emotional direction, visual principles, and experience rules of LUMORA.

LUMORA is not designed as a traditional portfolio website.

It is designed as a living digital experience system.

---

# 01. Brand DNA

## Brand Name

LUMORA

---

## Brand Meaning

LUMORA represents:

Light
+
Presence
+
Memory

The brand is built around the idea that digital experiences can feel alive.

---

# Core Statement

Designing digital experiences that feel alive.

---

# Brand Purpose

LUMORA exists to transform digital interfaces into memorable experiences.

The goal is not only visual beauty.

The goal is creating:

- Emotional connection
- Clear communication
- Meaningful interaction
- Lasting memory

---

# Brand Personality

LUMORA should always feel:

## Intelligent

The design shows thought and purpose.

## Cinematic

The experience feels like a carefully directed scene.

## Premium

Every detail feels intentional and refined.

## Calm

The interface never feels rushed or noisy.

## Human

Technology supports emotion instead of replacing it.

---

# 02. Experience Philosophy

## Core Belief

A website should not only be viewed.

It should be experienced.

---

# Experience Principles

Every interaction should achieve at least one:

## Reveal

Expose something meaningful.

Example:

A project world slowly becoming visible.

---

## Guide

Help users understand where to go.

Example:

Navigation and storytelling flow.

---

## Connect

Create an emotional relationship.

Example:

The final contact experience.

---

# Emotional Goals

Every LUMORA experience should create:

## Curiosity

"I want to explore more."

---

## Trust

"This designer understands quality."

---

## Connection

"This feels created by a thoughtful human."

---

# Design Philosophy

LUMORA follows this principle:

Less decoration.

More intention.

Every element must have:

- Purpose
- Position
- Behavior
- Meaning

---

# Experience Hierarchy

The priority order is:

1. User emotion
2. User understanding
3. Visual quality
4. Technical complexity

A beautiful experience that confuses users is not successful.

---

# Signature Principle

The user should recognize LUMORA even without seeing the logo.

The identity must exist through:

- Motion
- Atmosphere
- Interaction

- Emotional tone

# Final Brand Rule

Do not design pages.

Design moments.

Every major section should contain a memorable experience.

## Layer 01 — Outer Presence Field

Purpose:

Create environmental awareness.

Characteristics:

- Soft light field
- Atmospheric presence
- Very subtle movement

Behavior:

Always present, rarely noticed consciously.

---

## Layer 02 — Glass Core

Purpose:

Represent structure and intelligence.

Characteristics:

- Transparent depth

- Controlled reflection

Behavior:

---

## Layer 03 — Light Seed

Purpose:

Represent energy and life.

Characteristics:

- Internal glow
- Soft pulse
- Calm illumination

Behavior:

Creates the feeling of a living system.

# Core States

The Core has different states depending on context.

---

# State 01 — Dormant

Default state.

Used when:

- User is reading
- No interaction is happening

Behavior:

- Slow breathing light
- Minimal movement
- Calm presence

# State 02 — Aware

Triggered when:

- User moves cursor nearby
- User enters a new section

- Slight increase in presence
- Subtle light response

# State 03 — Focused

Triggered during:

- Important interactions
- Project exploration
- Contact actions

Behavior:

- More defined light
- Increased clarity
- Controlled energy

---

# State 04 — Rest

Used when:

- Transition ends
- Interaction is complete

Behavior:

Returns smoothly to Dormant state.

- Organic

- Intentional

# Core Timing

# 05. Motion Language System

Motion is a fundamental part of LUMORA identity.

Animation is not decoration.

Animation is communication.

Every movement must have:

- Purpose
- Timing
- Emotion
- Relationship with user action

---

# Motion Philosophy

LUMORA motion should feel:

- Cinematic
- Natural
- Calm
- Intelligent
- Controlled

The experience should feel like a carefully directed scene.

---

# Motion Principles

## 01. Intentional Movement

Every animation must answer:

Why is this moving?

If the movement does not improve:

- Understanding
- Focus
- Emotion

Remove it.

---

## 02. Organic Behavior

Movement should feel natural.

Avoid mechanical movement.

Prefer:

- Smooth acceleration
- Soft deceleration
- Natural rhythm

---

## 03. Spatial Awareness

Elements should feel like they exist in a space.

Use:

- Depth
- Layer transitions
- Environmental movement

Avoid:

- Flat appearance
- Random effects

---

# Motion Timing System

LUMORA uses controlled timing.

---

## Micro Interaction

Range:

150ms - 250ms

Used for:

- Buttons
- Small responses
- Cursor states

---

## Standard Interaction

Range:

300ms - 600ms

Used for:

- Components
- Reveals
- Interface changes

---

## Cinematic Transition

Range:

800ms - 1500ms+

Used for:

- Page transitions
- Environment changes
- Major reveals

---

# Easing Language

Preferred:

- Smooth curves
- Natural acceleration
- Controlled deceleration

Avoid:

- Bounce
- Elastic
- Overshoot
- Aggressive spring effects

---

# Scroll Experience

Scrolling is part of storytelling.

Scroll should reveal information gradually.

Use:

- Progressive reveal
- Depth changes
- Environmental evolution

Avoid:

- Excessive parallax
- Random movement
- Scroll effects without purpose

---

# Reveal System

Elements should appear through:

- Opacity transition
- Spatial movement
- Light interaction
- Depth emergence

The reveal should feel like discovery.

---

# Page Transition System

Moving between pages should feel continuous.

Preferred feeling:

A world expanding.

Not:

A new page loading.

---

Transition concept:

Current Environment

↓

Transformation

↓

New Environment

---

# Micro Interaction Rules

Small interactions should create confidence.

Examples:

Button:

- Soft response
- Clear feedback

Cursor:

- Context awareness

Cards:

- Depth response

Navigation:

- Calm state change

---

# Cinematic Signature

The unique LUMORA signature is:

Controlled cinematic interaction.

The user should feel:

"This experience has been directed."

---

# Performance Rule

Beautiful motion is useless if it damages performance.

Always prioritize:

- Smooth rendering
- Efficient animation
- Reduced unnecessary calculations

---

# Reduced Motion Support

Respect users who prefer reduced motion.

The experience should remain:

- Clear
- Premium
- Complete

without requiring animation.

---

# Final Motion Rule

Do not animate everything.

Animate what matters.
---
