# LUMORA Development Workflow


## Step 01 — Understand

Before coding:

Understand:

- Purpose
- User goal
- Experience goal


---

## Step 02 — Research Existing System

Check:

- Existing components
- Existing patterns
- Existing animations


Do not rebuild existing solutions.


---

## Step 03 — Design Alignment

Verify:

- DESIGN.md compatibility
- Brand consistency
- UX intention


---

## Step 04 — Implementation Plan

Define:

- Components needed
- Data needed
- Animation behavior
- Responsive behavior


---

## Step 05 — Build

Implement:

- Clean components
- Reusable logic
- Consistent styling


---

## Step 06 — Test

Check:

- Functionality
- Responsiveness
- Performance


---

## Step 07 — Review

Activate:

- Brand Guardian
- Motion Director
- UI System
- Quality Reviewer


---

## Completion Rule

A feature is complete only when:

It works.

It feels right.

It belongs to LUMORA.
