# Purpose

The Home page is not designed to sell.

It is designed to create belief.

Before users understand what LUMORA does,
they should feel what LUMORA is.

Every section exists to move the user through one emotional journey.

# Success Criteria

The Home page succeeds when:

- the user remembers the feeling
- the interface feels alive
- every section has purpose
- nothing feels excessive
- the experience feels unmistakably LUMORA
