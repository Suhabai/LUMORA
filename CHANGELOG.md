## [1.0.0] — 2026-07-28

### Added

- Initial release of LUMORA design system
- Dark-first color palette with purple accent system
- Fluid typography scale with Inter font
- GSAP and Framer Motion animation system
- Lenis smooth scrolling
- Reusable UI components: Button, Card, Badge, SectionHeader, Reveal, Counter
- Responsive layout with mobile navigation
- Skip-to-content accessibility link
- JSON-LD structured data
- Open Graph and Twitter Card metadata
- Sitemap and robots.txt
- Security headers
- TypeScript strict mode configuration
- ESLint configuration with Next.js rules

### Design Tokens

- Color palette: Background, Surface, Elevated, Border, Text, Accent, Glow
- Typography: Inter font family, fluid sizing
- Spacing: Container and section scales
- Border radius: sm, md, lg, xl, full
- Animation: Pulse, Float, Ring keyframes
- Easing: Custom cubic-bezier curves

### Components

- **Button**: Client component with Framer Motion hover/tap animations
- **Card**: Client component with hover lift effect
- **Badge**: Server component for status indicators
- **SectionHeader**: Server component with consistent heading pattern
- **Reveal**: Client component for scroll-triggered animations
- **Counter**: Client component with animated number interpolation
