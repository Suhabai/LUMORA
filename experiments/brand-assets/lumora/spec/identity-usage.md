# LUMORA — Identity Usage Map

Phase 0E.2.4 — Candidate Alpha (Quiet C)

---

## Asset Family

The LUMORA identity consists of two primary marks:

1. **Wordmark** — primary linguistic signature (Candidate Alpha — Quiet C)
2. **M Core (Micro-Mark)** — compact expression of the same typographic DNA

These are members of ONE identity family. They are NOT different logos.

---

## Wordmark Usage

### Hero

Use: `lumora-wordmark-master.svg` or `lumora-wordmark-large.svg`
Size: 120px+ cap height
Context: Full-page hero, splash, presentation title

### Header / Navigation

Use: `lumora-wordmark-medium.svg` or `lumora-wordmark-small.svg`
Size: 32-96px cap height
Context: Website header, compact navigation bar

### Footer

Use: `lumora-wordmark-small.svg`
Size: 24-48px cap height
Context: Site footer, copyright area

### Presentations

Use: `lumora-wordmark-master.svg`
Size: 120px+ cap height
Context: Slide decks, PDF presentations

### Print

Use: `lumora-wordmark-print.svg`
Size: Any
Context: Business cards, letterhead, print materials

---

## Prohibited Use

DO NOT:

- Use wordmark below 24px cap height
- Use micro-mark above 64px (use wordmark instead)
- Stretch, compress, skew, or rotate
- Add glow, gradient, shadow, or texture
- Recolor individual letters or elements
- Merge micro-mark into wordmark
- Redraw M Core into a generic M
- Use M Core as an unrelated decorative icon
