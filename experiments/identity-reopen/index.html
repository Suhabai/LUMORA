LUMORA — Identity Reopen Overview

Phase 0E.0 — Controlled Visual Reopening

Purpose

This experiment is a controlled visual reopening — not a redesign. The frozen production identity is not being replaced. This is an exploration to evaluate whether subtle refinements could strengthen what already works.

The current wordmark is proven. It works at every scale, in every context, beside the M Core. The question is: could it work even better?

Scope

Three files. No production changes. No frozen identity violations.

Wordmark Comparison Three directions at multiple scales, color tests, context simulations Navigation Access Work + About link prototypes using real routes

What Was Tested

  • 01Three SVG wordmark directions (A=current, B=Tense Counters, C=Restrained Hybrid)
  • 02Six scales: 240px, 120px, 48px, 32px, 24px, 16px
  • 03Four background contexts: light, dark, neutral, warm
  • 04Five usage simulations: nav bar, footer, hero, editorial, mobile
  • 05M Core compatibility at each scale
  • 06Navigation link access patterns (semantic route links)
  • 07Three hover styles (color shift, underline, opacity)
  • 08Mobile navigation prototype

Evaluation Questions

  • 01Does any direction feel like fashion branding rather than digital experience studio?
  • 02At 24px (favicon size), which direction remains most legible?
  • 03At 16px, does the O counter collapse in any direction?
  • 04Does the R leg in any direction feel ornamental rather than structural?
  • 05Does the A crossbar feel too high or too low in any direction?
  • 06When placed beside M Core, does any direction create visual tension?
  • 07Does any direction shift mood toward luxury/skincare/editorial fashion?
  • 08Which direction maintains the most digital and intelligent feeling?
  • 09Does any direction's rhythm feel rushed or compressed?
  • 10Which direction would represent LUMORA for the next 3 years?

M Core Compatibility Summary

Direction A (Current): Compatible. Proven in production. No changes needed.

Direction B (Tense Counters): Partial. M Core may appear broader than the condensed M at small scales. Requires visual verification at 24px and 16px.

Direction C (Restrained Hybrid): Compatible. Closest to A. M Core should remain clean at all scales.

Navigation Access Assessment

Current navigation uses 4 anchor links (#works, #philosophy, #about, #contact). The /work and /about routes exist but are not linked from navigation.

The proposed navigation adds two semantic route links (Work, About) alongside or replacing the current anchor links. The visual language is intentionally minimal: "Here are the two places you may want to go."

Three hover styles tested. Recommended: Style A (color shift) — matches current production pattern, most consistent with LUMORA's calm character.

Decision Framework

After reviewing the experiments, answer:

1. Is the current wordmark (Direction A) already optimal?

If yes: No change. The identity remains frozen. The experiment validated what exists.

If no: Which direction (B or C) strengthens LUMORA without shifting its character?

2. Should navigation include route links to /work and /about?

If yes: How many links? What visual treatment? What happens to current anchor links?

If no: The single-page experience remains the primary journey.

3. Does any change require updating the Identity Freeze document?

If the wordmark changes, the freeze must be updated with the new direction and rationale.
