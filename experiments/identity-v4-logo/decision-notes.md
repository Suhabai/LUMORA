# LUMORA Identity v4 — Logo Signature Exploration

Status: exploratory only. No production identity, frozen document, lockup, favicon, or Living Core source was changed.

## Design boundary

The existing Candidate Alpha / Quiet C wordmark and M Core remain canonical. This phase deliberately tests a reopened signature direction only. The studies are static; none imports Living Core behavior or uses pulse, orbit, morphing, sound, or interactive animation.

The palette is constrained to existing LUMORA surface values: void `#07070a`, accent `#8a2eff`, glow `#b96cff`, and text `#f5f5f7`. Violet glow is a presentation layer, never necessary geometry.

## A — Eclipse Core

One primary orbital contour creates presence around a central void. Its lower-right seam is deliberately small but authored: it breaks the generic-donut reading without becoming an active spinner. This is the quietest circular option and emphasizes awareness, horizon, and stillness.

## B — Threshold Ring

Two tapered contour segments create a narrow vertical threshold with an upper-left bias. It has the strongest directional silhouette of the three and reads as arrival or opening rather than an orb. The negative space is active, but no energy effect or portal depth is implied.

## C — Core / M Hybrid

An outer circular field holds a single internal V-based void. The internal architecture takes lineage from the frozen M Core’s structural dip without placing the production M inside a circle. It has the closest continuity with LUMORA’s current geometry while deliberately remaining a separate experimental symbol.

## Review lenses (not a ranking)

| Lens | A — Eclipse | B — Threshold | C — Hybrid |
| --- | --- | --- | --- |
| Distinctive decision | lower-right seam | tapered opening | M-derived negative space |
| Cinematic cue | horizon / awareness | arrival / threshold | held structure / presence |
| Small-size dependency | seam must remain visible | opening must remain clear | inner V must remain open |
| Monochrome test | contour only | contour only | field + void |
| Long-term applications | signature / social | header / wayfinding | signature / favicon candidate |

No winner is selected. The next decision is visual review, not integration.
