Part 1 — M/O Undercut Threshold

Five undercut values tested against BASE. All other variables identical. M/O-A mechanism: M right stem bottom extends inward.

Part 2 — O/R Release Threshold

Five R-leg release values tested against BASE. All other variables identical. O/R-C mechanism: R leg endpoint extends outward.

Part 3 — Combined Grid (3x3)

M/O: -10u, -15u, -20u crossed with O/R: +150u, +200u, +250u. 9 combinations. No individual letter redesign. Only measured values combined.

Part 4 — Optical Test

For every grid combination: readability, junction clarity, word rhythm, spatial balance, signature visibility, fashion/editorial drift, tech/dramatic drift, authorship, restraint.

Part 5 — Identity Threshold

For each value: INVISIBLE / BARELY PERCEPTIBLE / PERCEPTIBLE / SIGNATURE / OVERWORKED. Target: SIGNATURE without OVERWORKED.

Part 6 — Scale Test

Strongest combinations at 240, 120, 48, 24, 16 px. Plus actual rasterization at 16/24/48 x 1x/2x.

Part 7 — Real-World Digital Sizes

14px, 12px, 11px. Determine where custom details disappear. Wordmark must remain clear, balanced, recognizable.

Part 8 — One-Color Test

Black on white, white on black, knockout. No effects.

Part 9 — Human Review Layers

Three visual layers: BASE / OPTICAL SWEET SPOT / OVERWORKED. Establishes boundary between subtle identity and decoration.

Part 10 — Final Matrix

Complete evaluation table. Classification: REJECT / HOLD / ADVANCE.

Part 11 — Scale Dependency
