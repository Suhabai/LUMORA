# LUMORA Project Master Record

> Central reference for the LUMORA project. Aligned with DESIGN.md and AGENTS.md.

---

## Project Vision

LUMORA is a cinematic personal portfolio ecosystem.

It is not a template, framework, or generic website.

It is a complete experience system combining:
- Brand identity
- User experience
- Interface design
- Motion design
- Frontend engineering
- Emotional storytelling

The purpose is creating digital experiences that feel:
- Unique
- Memorable
- Human
- Intelligent
- Premium

---

## Brand Identity

**Name:** LUMORA
**Meaning:** Light + Presence + Memory

**Personality:**
- Cinematic — Carefully directed experience
- Premium — Every detail intentional
- Intelligent — Thoughtful and refined
- Calm — Avoids unnecessary noise
- Human — Technology supports connection

---

## Experience Philosophy

**Core Belief:** Every digital experience should create a meaningful connection.

**Experience Principles:**
1. Reveal — Guide users through discovery
2. Guide — Lead with intention
3. Connect — Create emotional resonance

**Emotional Goals:**
- Curiosity
- Trust
- Connection

---

## Core Concept

The Living Core is the emotional center of LUMORA.

It represents:
- A calm living identity system
- The presence of the brand
- A point of focus and connection

The Core must NEVER become:
- Generic glowing orb
- Sci-fi reactor
- Portal effect
- Random particle animation

---

## Design Principles

1. **Identity Over Trends** — Build a recognizable language
2. **Meaning Over Decoration** — Every element has purpose
3. **Experience Over Features** — Quality over quantity
4. **Consistency Creates Identity** — Repeated meaningful patterns
5. **Simplicity Creates Luxury** — Controlled simplicity

---

## Architecture Direction

**Framework:** Next.js 16 (App Router)
**UI:** React 19
**Language:** TypeScript 5 (strict)
**Styling:** Tailwind CSS v4
**Animation:** Framer Motion + GSAP + Lenis

**Component Architecture:**
- `components/ui/` — Reusable primitives
- `components/layout/` — Structural components
- `components/sections/` — Experience sections
- `constants/` — Content and configuration
- `tokens/` — JSON design tokens
- `styles/` — Global styles and CSS variables

**Route Structure:**
- `/` — Home experience
- `/work` — Portfolio overview
- `/work/omnia` — OMNIA project world
- `/work/nexora` — NEXORA project world
- `/work/velocity` — VELOCITY project world
- `/system` — Design system documentation
- `/docs` — Technical documentation
- `/about` — About experience
- `/contact` — Contact experience
